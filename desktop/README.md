# Grok Build GUI RU — оболочка Electron

Подробная русская документация, скриншоты, установка, модели и сведения о приватности находятся в [основном README](../README.md).

```powershell
npm ci
npm run verify
npm run test:localization
npm start
```

Для обезличенного визуального предпросмотра: `npm run preview`, затем откройте `http://127.0.0.1:4174`.

Сборка Windows-установщика: `npm run dist -- --win nsis --x64 --publish never`.
