# Grok Build GUI — русская версия

Неофициальная русификация [Grok Build GUI](https://github.com/Jane-o-O-o-O/grok-build-gui), основанная на версии 0.1.1. Это общественный проект, не официальный продукт xAI.

Интерфейс по умолчанию — русский. Переведены меню, настройки, поиск, команды, Git, терминал, браузер, память, разрешения, вход в аккаунт, уведомления и ошибки локальных компонентов. Китайский язык удалён из интерфейса. Английский можно выбрать в настройках.

Язык ответов самой модели задаётся запросом пользователя. Содержимое файлов проекта, пользовательские диалоги и внешние сообщения Grok Runtime не изменяются русификацией.

## Запуск из исходников

Нужны Node.js и установленный официальный Grok CLI.

```powershell
cd desktop
npm ci
npm run verify
npm run test:localization
npm start
```

Для Windows-установщика: `npm run dist -- --win nsis --x64`.

## Изменения русской версии

- Полный русский словарь интерфейса и параметров Runtime.
- Русские подписи и подсказки в HTML, включая начальное состояние экрана.
- Русские сообщения ошибок в основных локальных компонентах.
- Однократное переключение существующих настроек на русский с сохранением остальных данных.
- Проверка отсутствия китайских иероглифов в коде поставляемого интерфейса и совпадения параметров перевода.
